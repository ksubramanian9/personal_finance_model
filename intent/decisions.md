# Decisions Log

**Summary:** What we chose, what we rejected, why. Read before re-opening a settled question.

| # | Decision | Rejected | Why |
|---|---|---|---|
| 1 | Educational/exploratory tool for young professionals | Planner (B), game (C) | Planner needs high fidelity and carries advice liability; game over-emphasises scoring |
| 2 | Thick personas, 4-5 archetypes, extensible via JSON | Thin profiles | Behavior biases make personas distinct and feed nudges |
| 3 | Yearly tick; stage-driven decisions; decade cards expand to years | Monthly tick; stage = decade | Yearly is enough fidelity; stages need not be round decades |
| 4 | Retirement age user-overridable | Fixed per persona | Core to the headline outcome |
| 5 | Seeded RNG, same-seed comparison, seed behind advanced toggle | Unseeded; Monte Carlo in v1 | Reproducibility, testing, counterfactuals; Monte Carlo pushes toward a planner |
| 6 | Capability: 3 tracks, money + effort; default single choice | Single skill number; full skill tree | Trade-offs matter but must not overwhelm |
| 7 | India fidelity "Medium", including capital gains | Light; Heavy | Cultural realities teach more than tax precision. Capital gains pulled into Medium on request |
| 8 | Outcome = headline question + measures + light wellbeing; no composite score | Net worth only; composite score | Composite invites gaming and bakes in values |
| 9 | Root intent.md of about one page plus per-concern files | Single flat doc | Progressive disclosure applies to the documentation too |
| 10 | Staged roadmap v1/v2/v3 | Everything at once | Prove the loop first |
| 11 | Three disclosure levels with rules | Ad-hoc disclosure | Core requirement made concrete |
| 12 | Vanilla JS, pure engine, JSON data, no library | Framework; charting library | Small scale; custom look; simplicity |
| 13 | Today's rupees default, nominal toggle at Level 2 | Nominal only | Nominal misleads over 60 years |
| 14 | Family: choices and events, spouse as a parameter | Fixed family; full household sim | Keeps choice without doubling the engine |
| 15 | Nudges the user can resist, plus visible slow drift | Silent behavioral drift; no behavioral modeling | Honest and educational |
| 16 | Illustrative seed data with basis/confidence/asOf; sourcing for high-impact numbers | All guessed; all sourced | Truthful without swallowing the project |
| 17 | Macro regimes link shocks | Independent draws | Correlated pain is why liquidity and insurance matter |
| 18 | Choices are data: a decision library plus stages in `stages.json`; picks persist until changed | Hard-coded stage screens | Adding a choice or stage is a data change, like personas |
| 19 | Stage flow lives in `flow.js`, testable in Node with a fake DOM | Flow inside `main.js` | UI behavior could not be tested otherwise; it caught a real bug |
| 20 | Retirement age is a decision in the last stage, applied before playing it | Fixed at the start only | Intent says it is overridable at pre-retirement |
| 21 | Equity return parameters are arithmetic means calibrated so the compounded (geometric) return matches the sourced CAGR | Using the CAGR directly as the mean | A random simulation compounds at roughly mean minus half the variance; using 12.4% as the mean would have given about 10.6% |
| 22 | One economy-regime table drives inflation, market returns and raises; the job's `cyclicality` scales the raise effect | Independent shocks per asset | Correlated pain; government job stays steady, IT job swings |
| 23 | New savings follow the player's mix; existing holdings are never sold to rebalance; provident funds are locked | Auto-rebalance each stage | Rebalancing would trigger tax and hide the lesson that switching late is slow |
| 24 | Calibration is enforced by tests (long-run mix, compounded returns, inflation, ordering) | Trusting the numbers by eye | Data edits that break the sourced anchors fail loudly |
| 25 | Events use their own random stream and never depend on what the player buys, saves or invests; skill (`capabilityEffect`) shifts only the odds | One shared stream; choices that change which events happen | Same seed + different choices must show the same luck. Skill is the intended exception (intent: layoffs hit lower-capability people harder) |
| 26 | Insurance and an emergency fund are decisions in the early and family stages (health again before retirement) | Always on; or a separate screen | They persist like other choices and keep Level 1 to one question at a time |
| 27 | Term life insurance is deferred to the family increment | Build it now | Nothing can kill the breadwinner until family exists, so it would have no effect |
| 28 | Persona base pay growth lowered for IT (9 to 7%) once job offers became explicit events | Keep 9% | Switching premiums were counted twice |
| 29 | Chart colours come from the dataviz skill's validated palette (first five slots, fixed order), not the playful game accents | Reuse the game's accent colours | The validator proves colour-blind separation; the game palette is for chrome, the chart palette is for data. Aqua, yellow and magenta are under 3:1 on white, so a legend, readout and table twin ship with every chart |
| 30 | Each decade's "Why?" draws its own net-worth chart; the whole-life chart stays on a linear scale and says so | Log scale; hiding small segments; drawing slivers at a minimum height | A lifetime peak of crores makes early cash and loans invisible. Bending the scale or drawing fake slivers would mislead; zooming by decade shows them honestly |
| 31 | Net-worth "bridge" with an explicit inflation line in today's rupees | Deflating the end figures only | Every line adds up exactly from start to end in both rupee modes, so the explanation can be trusted and tested |
| 32 | The level of detail, once raised, persists for the session | Reset on every screen | A player who asked "why?" once should not have to ask at every stage; they can hide it with one tap |
| 33 | Only the new tax regime is modelled; slabs, the standard deduction and the capital-gains exemption are assumed to rise with prices | Old regime too; fixed rupee slabs | Fixed slabs would push every long career into the top bracket by inflation alone, which real governments reset; a real-terms table keeps the lesson about rates, not drift. Old-vs-new stays out of scope |
| 34 | Persona salaries are gross pay; tax is worked out once a year on pay, taxable windfalls and interest, plus gains realised when assets are sold | Treat salary as take-home; tax unrealised gains each year | Tax on unsold gains does not exist in India; it only bites when you sell, which is the point of the "selling early vs late" lesson. Net worth before retirement is therefore before that tax |
| 35 | Gains are tracked per purchase (oldest sold first) so holding period decides long- vs short-term; tax on a sale is raised by selling a little more | One average cost; paying tax the next year | The holding-period rule is the lesson, and it needs real purchase years. Raising the tax in the same year keeps each year's books closed |
| 36 | The tax drag shows as two bridge lines: tax on pay and windfalls, and the extra tax investing brought | One tax line | Splitting them shows how much of the bill is the job and how much is the portfolio |
| 37 | Long-run inflation lowered from 5.2% to 4.5% (boom 5.1, steady 4.3, slowdown 3.8, crisis 5.3); persona base pay growth lowered by the same 0.7 points (IT 7 to 6.3, government 6 to 5.3) | Keep 5.2%; lower inflation but leave pay growth alone | 5.2% (the 2012-26 average) made prices rise 24 times over a 63-year life, and sits above the RBI's 4% target. Pay growth is nominal, so leaving it alone would have quietly raised real pay growth by 0.7 points a year (about 30% more real income by 60). Asset returns are left as sourced, so real returns on investments are about 0.7 points higher than before |
| 38 | Housing v1 is one buy-or-rent choice: rent split out of living costs, a single home purchase at a stage, no upgrades, second property or rental income | Rent only, buy later; full property life | The home loan as the biggest asset and debt is the main Indian lesson; a full property life would bury the others |
| 39 | Home price follows the economy mildly: it moves with the same regime weather, calmer than shares, a little above inflation long-run, with a level set by city tier | Fixed growth with no luck; local boom and bust separate from the economy | A home that can never fall hides a real risk, but separate local swings are hard to explain and would swamp other lessons |
| 40 | Home loan: about 80% of the price, 20 years, one fixed rate, fixed EMI, no prepayment | Floating rate; yearly prepayment | One loan is easy to understand; the EMI keeps running through a layoff, which is the lesson. Prepay-or-invest and rate risk are for later |
| 41 | Buying needs the down payment and one-off costs in cash and sellable savings (tax applies on sales); otherwise the option stays closed and shows the shortfall | Borrow the shortfall; the game picks a cheaper home | Keeps the size of the bet the player's choice and avoids a debt spiral every player walks into |
| 42 | A home counts in net worth with its own colour but is not "spendable" for the stop-working test; it is sold as a last resort, with costs and tax, after other assets | Count fully everywhere; ignore until sold | You cannot eat your living room, but the biggest asset in most Indian lives must be visible, and it can be a cushion of last resort |
| 66 | Four more personas (a freelance designer, a resident doctor, a school teacher, a family-shop heir) built from the same persona fields, with two optional fields (own severance, own event wording) | New engine mechanics per persona (irregular monthly income, a shop with property); more of the same salaried types | The existing levers (cyclicality, layoff risk, benefits, debt, family load, biases) already make them play differently; a freelancer losing a big client is the same mechanism as a layoff, so only the words and the severance needed to change |
| 67 | The colour theme has a three-way button at the top right (Automatic, Light, Dark), remembered in the browser; Automatic follows the device and its changes; a URL choice applies to one visit only | A two-way switch; no button | Most people want the device's setting, some want to override it, and the button needs to say what it will do. A fixed button needs room above the first heading on phones |
| 43 | The home question is asked only at the start of the 30s and 40s stages and only while renting; home prices use no random draws | Ask every stage; give prices their own random noise | Two decision points are enough to teach timing; deterministic prices keep every existing seed's economy and events identical |
| 44 | A home is sold only if, after cash and every liquid holding, the shortfall would take personal debt above 12 months of pay | Sell whenever cash runs out; never sell | A small gap is a loan, not a reason to lose a home; a ruinous gap forces the lesson that a home is a cushion of last resort |
| 45 | Marriage, wedding size, the partner's work and children are choices that happen on a schedule (a planned age, then fixed gaps between births); a decision can be conditional ("onlyIf") on the state and on earlier answers in the same stage | Random marriage and births; asking every question in every stage | The same choices always give the same family, so same-luck comparisons stay clean, and a single player is not asked about weddings |
| 46 | A partner is a share of the player's pay, taxed separately, with no career of their own; wedding sizes are game presets of 5, 15 and 40 lakh | A full second person with their own job, skills and risks; a free-form wedding budget | Matches the earlier decision that the spouse is an income parameter, not a simulated person |
| 47 | A child costs a yearly amount by age band in today's rupees (about 50 lakh by 21 in a metro, 65% of that in a tier-2 city), with school and college fees rising 3 points faster than prices | One flat cost; the published 1 crore-plus totals | Keeps the shape of Indian child costs (a big first year, school, then college) at the low end of sourced totals, so an ordinary family can survive; education inflation is the lesson |
| 48 | Family changes money only: no random draw is added or moved, so the same seed gives the same economy and events however the family choices go | Family-dependent event odds | Keeps same-luck replay exact |
| 49 | Life length is random and hidden until the end: mean 80, spread 8 years, 68 to 100, on its own random stream, independent of choices | Fixed at 85; shaped by health cover and choices | Longevity risk is the lesson, and nobody can plan to the day; own stream keeps every existing seed's luck; unsourced effect sizes for choices would blur the point |
| 50 | After the last stage the retirement years are played to the end of life. The player chooses a spending level (Comfortable 100%, Modest 75%, Lean 55%); provident funds unlock after fixed deposits; the government persona gets a pension of 30% of last pay; support and employer health cover end | Fixed 75% spending; a "4% rule" withdrawal | Spending is the biggest lever on whether money lasts, and the player should hold it. Employer cover ending makes the health-cover choice matter |
| 51 | The verdict has three answers (lasted / sold the home / ran out, with the age), plus years of cover, the pension and what was left, and no composite score | A single score; a bare yes or no | The headline stays one question and a plain answer; the home sale and the age make the answer teachable |
| 52 | Lifestyle drift: a persona's share (lifestyleCreep) of any real pay rise becomes permanent extra spending, shown as its own bridge line | No drift; a flat savings rate only | Without it nothing could ever fail: pay grew several-fold against fixed living costs, and 97% of lives retired with decades of cover |
| 53 | The pension is 30% of the last whole-salary pay, not 50% | 50% of pay | The Unified Pension Scheme pays 50% of basic pay, and basic pay is roughly 60% of the whole salary (an unsourced estimate); at 50% the government persona could never run short |
| 54 | Skills are one stock that builds with effort with diminishing returns, fades by 10% a year, builds less with age and in bad times, and adds up to 3 points of yearly pay growth times the persona's skillPayoff | A constant extra raise for as long as the choice stands | The old constant raise made going all in the best choice for everyone; a stock makes it a sustained commitment with a ceiling |
| 55 | Going all in carries a burnout risk that scales with effort squared (about 5% a year at full effort), costing months of mostly unpaid leave | A fixed wellbeing penalty with no money consequence | Burnout is the real price of overwork; being random and costly, it makes going all in a gamble, and it lets the signal be about what actually happened |
| 56 | Wellbeing is a light "how it felt" line (balanced / stretched / burnt out) from years of all-in effort and burnouts, not a number | A 0 to 100 wellbeing score | No composite scores (an earlier decision); a plain sentence is enough to start a conversation |
| 57 | Appending a life event shifts the luck of every later year, because each event takes three draws each year; the burnout event did that once (decision 25's "append at the end" only protects the first year) | Giving burnout its own random stream | Nothing is stored yet, so a one-time shift is cheap; the golden values were re-pinned. A published replay link would need the separate stream |
| 58 | Instinct cards pause a stage in the moment; four cards (crash, raise, festival, hot tip); the player always chooses and nothing is pre-selected; traits set frequency and how loudly the gut speaks; at most two ordinary cards a stage, the crash card always | Standing rules chosen up front; results reported afterwards; traits that decide for the player | Instinct is about acting in the moment, and standing rules would turn it into planning. Nothing silently overrides the player |
| 59 | Following a card works through the next year's books (a pending sale, spend or windfall), never by editing history; cards come from their own random stream with four fixed draws a year | Drawing from the main or events stream | The tax and funding machinery already handles the money; a separate stream keeps every other seed's luck unchanged and makes "resist everything" exactly the old game |
| 60 | The browser saves a life in progress (at each stage's questions, each instinct card and each result), the level of detail, the rupee mode and the last persona; a finished life is not kept; everything is local and can be forgotten with one button | Settings only; a history of finished lives | A life takes 15 to 30 minutes and losing it is the most annoying failure; a history of lives would add a list screen and nudge the game towards a planner |
| 61 | Level 3 offers a seed box, four economy scripts, three number shifts plus "no tax", and a read-only data browser; changes apply to one life and are marked on its end screen | Seed and browser only; editing any number | Economy scripts and a few shifts answer the questions people actually ask (what if there were a crash then? what if inflation were higher?) without letting a silly value break the game; the marking keeps custom lives from passing as default ones |
| 62 | The phone pass keeps charts at a readable minimum width and lets them scroll sideways; focus moves to each new screen's heading and the main area is not a live region | Shrinking charts to fit; an aria-live region that re-reads whole screens | Small SVG text is the known phone problem; the readout and table already carry the facts, and re-reading a whole replaced screen to a screen reader is noisy |
| 63 | Disclaimer: the footer line stays on every page and an About panel carries the full wording, the list of simplifications and the privacy note; text lives in JSON | Footer only; a separate page | A short line is always visible and a fuller, honest statement is one tap away without losing the game underneath |
| 64 | Dark scheme follows the device setting (and a URL override), with its own validated chart colours | A manual toggle only; light only | People expect the device setting; the toggle can come later. The chart palette was re-validated against the dark surface rather than inverted |
| 65 | The test suite runs in a real browser too: ui/dom.js takes a swappable document so the fake-DOM UI tests work there, and smoke.html plays whole lives through the real screens | Node-only tests | The first real-browser run found 78 of 364 tests failing, all because the browser's own document cannot be replaced; the app itself was fine, but only a real run could show that |
